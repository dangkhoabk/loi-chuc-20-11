# Tri Ân Thầy Cô - 20/11

Trang chúc mừng ngày 20/11 được làm theo phong cách tươi sáng, ấm áp và dễ chia sẻ. 

## Tính năng
- Giao diện hiện đại, thân thiện và tối ưu cho điện thoại
- 3 lời chúc mẫu thay đổi theo lần nhấn
- Khung viết lời chúc riêng
- Nút chia sẻ và sao chép liên kết
- Sẵn sàng chạy trên GitHub Pages

## Mở trên GitHub Pages
1. Push file `index.html` lên nhánh `main`
2. Vào repository -> Settings -> Pages
3. Chọn `Deploy from a branch`
4. Chọn nhánh `main` và thư mục `/ (root)`
5. Lưu và chờ triển khai
